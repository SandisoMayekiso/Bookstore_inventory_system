# 📚 Bookstore Inventory System (Python + Tkinter + SQLite)

A graphical **Bookstore Inventory Management System** using **Python Tkinter** and **SQLite3**.  
This project allows users to manage books visually via buttons, forms, and listboxes.

---

## 🚀 Features
- 🆕 Add, view, search, update, and delete books  
- 🧭 Scrollable listbox to browse book records  
- 🎨 Modern, clean GUI with color-coded buttons  
- 💾 Data persistence with SQLite database  

---

## 🧠 Tech Stack
- **Python 3.x**
- **Tkinter (GUI library)**
- **SQLite3**
